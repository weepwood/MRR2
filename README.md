# MRR2

MRR2 是以 [MRR](https://github.com/weepwood/MRR) 业务结构为基础制作的独立视觉验证项目，用于评估一套更清爽、克制的病案管理界面是否适合未来迁移回 MRR。

> 本仓库仅包含前端原型和 Mock 数据，不连接 MRR 后端，不读取数据库，也不访问真实病案影像。

## 设计方向

项目采用“Vercel 的结构秩序 + Linear 的深色质感”：

- 深色导航用于稳定视觉重心和建立产品氛围；
- 浅色主工作区用于保证表格、表单与长时间操作的可读性；
- 细边框优先于明显阴影；
- 统一使用 4 / 8 / 12 / 16 / 24 / 32 的间距系统；
- 光晕只用于首页、系统状态和当前选中项；
- 支持完整深色模式，用于比较不同的融合比例；
- 不使用 TailwindCSS，样式由原生 CSS 与设计令牌管理；
- 构建目标为 Chrome 109，便于评估 MRR 的兼容性要求。

## 已实现页面

- 管理概览：核心指标、扫描趋势、基础设施和最近病案；
- 影像档案袋：检索、患者信息、影像分类、网格与列表视图；
- 记录管理：筛选、状态、数据表格与分页；
- 病案扫描统计：趋势、状态分布和科室完成情况；
- 系统监控：服务健康、资源使用、接口延迟和最近事件；
- 系统设置：界面模式、视觉偏好和设计参数展示。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 建议评估重点

1. 深色导航与浅色工作区是否符合日常使用习惯；
2. 首页的 Linear 风格光感是否过强或过弱；
3. 表格行高、字体和信息密度是否适合医院内网环境；
4. 影像档案袋的分类侧栏与缩略图比例是否合理；
5. 全深色模式是否值得在 MRR 中作为可选主题保留；
6. 哪些页面适合先迁移，哪些页面应保留当前 MRR 设计。

## 与 MRR 的关系

MRR2 不是 MRR 的替代版本，也不会与 MRR 共用发布流程。后续如果验证结果合适，建议先抽取设计令牌与基础组件，再按页面逐步迁移，避免一次性重构造成业务回归风险。
